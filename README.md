# FIRMA23 Ops

Internal operating system for the EVEN / Secretaria de Economia digital transformation program.

This repository is intentionally separate from the FIRMA23 public website. It will contain the private application used to register beneficiary companies, manage package delivery, assign operators, record collections, approve allocations, and display team performance.

## Start here

1. Read `AGENTS.md`.
2. Read every file under `docs/`.
3. In Conductor, begin with the prompt in `docs/CONDUCTOR-START.md` using Plan Mode.
4. Do not create a production Supabase project or Vercel deployment until the local prototype and financial rules have been approved.

## Current status

Greenfield repository. No application code, dependencies, credentials, Supabase project, or Vercel project has been created yet.
